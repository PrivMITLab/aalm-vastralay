# UI/UX Pro Max

## Core Principles
1. **Bento Grid 2.0 Architecture:**
   - Asymmetric, content-prioritized visual containers with fluid responsive breakpoints.
   - Distinct hierarchy: Primary hero cards (spanning 2 columns), accent cards, and auxiliary status tiles.
2. **APCA (Advanced Perceptual Contrast Algorithm):**
   - High perceived readability for body text (Lc > 75), headings (Lc > 60), and secondary captions (Lc > 45).
   - Never place low-contrast grey on white or dark muted text on dark surfaces.
3. **Indian Ethnic Brand Aesthetics:**
   - Premium Royal Crimson / Deep Maroon (`#881337`), Antique Gold (`#ca8a04`), Warm Cream (`#fdfbf7`), and Emerald Green (`#059669`).
   - Tactile shadows, micro-borders with subtle opacity (`border-maroon-900/10`), and soft radii (`rounded-2xl`).
4. **Accessibility (WCAG 2.1 AA):**
   - Minimum tap target 44x44px for touch interfaces.
   - Visible high-contrast focus rings (`focus-visible:ring-2 focus-visible:ring-maroon-700`).
   - Semantic HTML and ARIA labels on all interactive controls.
